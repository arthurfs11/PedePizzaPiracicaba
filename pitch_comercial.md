# Pitch Comercial — Pede Pizza (SaaS)

> Sistema completo de pedidos digitais para pizzarias e restaurantes — canal próprio, sem comissão de marketplace.

---

## 1. O Problema

Todo dono de pizzaria enfrenta a mesma armadilha:

| Situação | Impacto |
|---|---|
| iFood/Rappi cobram **15% a 30% de comissão** por pedido | Margem destruída |
| Pedidos por WhatsApp são **manuais e caóticos** | Erros, atraso, retrabalho |
| Sem histórico de clientes | Sem fidelização |
| Sem relatórios de vendas | Decisões no escuro |
| Telefone congestionado nos picos | Clientes perdidos |

**Uma pizzaria faturando R$ 10.000/mês no iFood paga até R$ 3.000 em comissão — todo mês, para sempre.**

---

## 2. A Solução

**Pede Pizza** é um sistema white-label de pedidos digitais com canal próprio: o cliente pede direto pela loja, sem intermediário.

```
Cliente pede  →  Bot Telegram  →  Painel da loja  →  Cozinha
                 ou Web Chat        (tempo real)
                 ou Cardápio
                    Online
```

O dono da pizzaria tem tudo em um só lugar: pedidos chegando em tempo real, clientes cadastrados, relatórios, cardápio editável, pagamento via Pix automático.

---

## 3. Canais de Pedido (Multi-canal)

| Canal | Como funciona |
|---|---|
| 🤖 **Bot Telegram** | Cliente conversa com o bot, monta o pedido e confirma |
| 💬 **Chat Web** | Link público no site/Instagram, interface de chat |
| 🍕 **Cardápio Online** | Página pública com carrinho dinâmico, igual ao iFood |
| 📋 **Pedido Manual** | Operador lança pedido recebido por telefone no painel |

Todos os canais chegam no mesmo painel kanban, em tempo real.

---

## 4. Funcionalidades Completas

### 🎛️ Painel de Operação
- **Kanban em tempo real** com 5 colunas: Aguardando Pix → Recebido → Em preparo → Saiu para entrega → Concluído
- Timer ao vivo em cada pedido (alerta visual quando demora muito)
- Notificação sonora a cada novo pedido
- Impressão térmica 80mm com 1 clique
- Atualização de status notifica o cliente automaticamente no Telegram

### 🛵 Gestão de Entregadores
- Cadastro de entregadores com status em tempo real (Disponível / Em entrega)
- **Atribuição automática**: ao mover o pedido para "Saiu para entrega", o sistema designa o primeiro entregador disponível sem nenhum clique extra
- Troca de entregador direto no card do kanban — sem sair da tela de operação
- Status atualiza automaticamente: quando a entrega é concluída, o entregador volta para "Disponível"
- Visão centralizada: página dedicada com painel de quem está livre e quem está em campo

### 🍕 Cardápio Dinâmico
- Gerenciamento completo: pizzas, tamanhos, bordas, acompanhamentos
- Ativar/desativar itens instantaneamente
- Sincronização automática com o bot em até 30 segundos

### 👤 Clientes
- Cadastro automático a cada pedido
- Histórico completo de pedidos por cliente
- Endereço salvo — cliente não precisa digitar de novo
- Busca e gestão pela equipe

### 💰 Pagamentos
- **Pix automático via AbacatePay** — confirmação instantânea, pedido entra sozinho
- **Pix Copia e Cola** — fallback manual, zero configuração extra
- Pagamento na entrega

### ⭐ Programa de Fidelidade
- Configurável: "a cada X pedidos, desconto de Y%"
- Aplicado automaticamente no checkout
- Incentiva recompra sem trabalho manual

### 🏘️ Entrega por Bairros
- Cadastro de bairros com taxa de entrega individual
- Calculado automaticamente no checkout do cardápio online
- Sem surpresa para o cliente, sem erro de cobrança

### ⚙️ Configurações da Loja
- Horários de funcionamento por dia da semana
- Bot e cardápio web bloqueiam pedidos fora do horário automaticamente
- Tempo estimado de entrega configurável

### 📊 Relatórios
- Faturamento por período
- Volume de pedidos por canal
- Exportação CSV para contabilidade

### 🔐 Controle de Acesso
- Papéis: Operador, Admin, Contábil, Super Admin
- Cada função vê apenas o que precisa
